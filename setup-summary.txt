✅ 완료된 설정
================================================================================

📁 프로젝트 구조
  • app/ - expo-router 기반 화면 라우팅
  • components/ - 재사용 가능한 React 컴포넌트
  • services/ - API 서비스 (newsService.ts 포함)
  • utils/ - 유틸리티 함수 (api.ts 클라이언트 포함)
  • types/ - TypeScript 타입 정의
  • hooks/ - 커스텀 React Hooks
  • context/ - React Context 상태 관리
  • constants/ - 앱 전체 상수
  • assets/ - 이미지, 폰트 등

⚙️ 코드 스타일 설정
  ✓ ESLint (eslint.config.js) - ESLint 9 형식
  ✓ Prettier (.prettierrc.json) - 코드 포매팅
  ✓ TypeScript (tsconfig.json) - Strict 모드 활성화

📝 개발 도구
  ✓ ESLint: npm run lint
  ✓ Prettier: npm run format
  ✓ TypeScript: npm run type-check
  ✓ ESLint 자동 수정: npm run lint:fix

🔐 타입스크립트 경로 별칭
  @/* → 루트 디렉토리
  @/components → components
  @/services → services
  @/utils → utils
  @/types → types
  @/hooks → hooks
  @/context → context
  @/app → app

🌍 환경변수
  • .env.example - 환경변수 템플릿
  • .env.local - 로컬 개발 설정 (생성됨)

📚 문서
  ✓ README.md - 프로젝트 개요
  ✓ CODE_STYLE_GUIDE.md - 상세 코드 스타일 가이드
  ✓ SETUP_GUIDE.md - 초기 설정 가이드

🚀 시작하기
================================================================================

1️⃣  개발 서버 시작
   $ npm start

2️⃣  플랫폼 선택 (메뉴에서)
   • i - iOS 시뮬레이터
   • a - Android 에뮬레이터
   • w - 웹 브라우저

3️⃣  코드 작성 후 저장
   → Hot reload 자동 적용

4️⃣  코드 품질 유지 (커밋 전)
   $ npm run lint:fix
   $ npm run format
   $ npm run type-check
